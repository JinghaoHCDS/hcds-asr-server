## 已验证的行为

- 真实 FFmpeg 8.1.1 编解码：横屏、竖屏、旋转元数据、4K 缩小、低分辨率不放大、可变帧率、音画起点偏移、封面图排除、无音轨拒绝、可读容器但尾部损坏。输入与保存视频均完整解码检查。
- 合成闪光和音调在前、中、后三处解码测量，音画同步及转录到播放器映射误差均不超过 150 ms。该结论仅覆盖测试中的短合成素材，不能替代长面试验证。
- 视频失败后音频转录继续；单独重试视频不重编码 MP3、不改变稿件版本或到期时间。Range 返回 206，账户隔离生效；资产与预留账目结算后不重复计费。
- 真实编码取消与额度拒绝回收临时文件；集成测试模拟编码在取消／删除之后返回，不能提交晚到结果或遗留未提交视频。播放消费者退出后才删除资产。
- 模拟中断准备状态后的服务重启恢复、schema 5→6 保留稿件与期限、将到期时间提前后的清理通过。不是持续七天运行或进程强杀验收。
- MOSS 工作台请求冻结 auto 与 65536；人物统一改名、单段改归属、创建人物、版本冲突、原文及原归属保留、历史版本 Markdown、MOSS 改字保留段级时间、既有字幕导出通过。识别结果使用 mock，不代表真实模型识别质量。
- 既有 Anchor Replay 测试继续覆盖跨块编号置换、人物暂时缺席后返回、晚加入候选、短回答及无法关联情形，未修改声学阈值。
- Markdown 保留缺口、未确定及分块内来源；合并受人物、时间间隔、总时长、字符数约束，重叠、空段或待确认边界阻止合并，历史版本不会被改写。
- 本地 Chromium 浏览器使用合成视频完成上传、人物改名、单段文字／归属修改、人物筛选、播放定位、音视频切换、Markdown 下载。检查窄屏滚动与编辑弹窗、Tab／Escape 操作；不是手机实机触控验收。临时账户、数据及浏览器工作空间已退出，测试素材不作为产品附件保存。

## 尚未验证与发布条件

需要用户提供超过 30 分钟的三人混合音轨面试录像，并给予本任务 Windows 执行及素材传输范围授权。对同一素材比较 `speaker_resolution=off/auto`，人工核对首次发言、块边界、长时间沉默后重返、抢话及短回答，记录错归属、换号、未确定、漏词、耗时与 CPU／内存／显存／磁盘使用。无人工参考部分不报告准确率，人数恰好为三不构成质量通过。

还需验证目标机器的 CPU 压缩耗时、长素材同步与可接受画质／听感。HDR 当前拒绝生成回看视频并保留源文件，音频转录可继续；未实现 HDR 色调映射。旧任务源视频已删除时无法补回，需重新上传。

生产发布另需当次授权，并保留匹配源码、前端与数据快照；本记录不替代 GPU 或生产验收。产品和接口以[工作台契约](../reference/product-workbench.md#视频回看与人物校对schema-6)为准。

[MOSS 官方说明](https://github.com/OpenMOSS/MOSS-Transcribe-Diarize#serve-with-sglang-omni)提示长多人录音提高生成上限，并以 65536 举例。本项目沿用已锁定的 Transformers 路径，此处只采用生成预算，不变更推理后端。视频参数参考 [FFmpeg 编码说明](https://ffmpeg.org/ffmpeg-codecs.html)和[MP4 封装说明](https://ffmpeg.org/ffmpeg-formats.html)，具体行为以本次真实 FFmpeg 测试为证。
