## 主题和动效

用户指定从 `myContentMachine` 读取主题。颜色和字体来自该项目 `AI_Content_Workspace/06_System/hcds-brand-dna.md`（1.3.0）及 `hcds-html-design-system.md`：

- 雾蓝 `#BECBEB`：侧栏、播放器和素材区的空间层次。
- 卡布里蓝 `#0C91FA`：当前导航、操作焦点和进度；按钮底色与纸白混合，以保证墨灰小字可读。
- 麦黄 `#EBCB75`：保留期提示、搜索命中及待复核标记。
- 墨灰 `#343A46`、纸白 `#F7F7F4`：正文与阅读底色。
- 中文标题优先霞鹜文楷，正文优先 MiSans，并提供系统回退；不请求外部字体 CDN。

使用真实 GSAP `3.15.0` 执行页面、登录、结果面板、窄屏工具切换和编辑浮层入场。依据[官方 matchMedia 文档](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)作用域管理与 `revert()` 清理，轮询不重播页面动画，尊重 `prefers-reduced-motion`。没有将推理中的未知进度做成虚假百分比。

## 长转录布局

应用占据 `100dvh`。结果页播放器、文本工具栏和底部状态保持可用；正文与导出／复核侧栏分别滚动。窄屏在正文和工具面板间切换，不将工具堆在全文之后。

正文采用 `@tanstack/react-virtual` 的动态高度虚拟列表，保留完整结果，只挂载可见片段及少量缓冲行；没有将全文截断为预览。参照[官方 virtualizer 文档](https://tanstack.com/virtual/latest/docs/api/virtualizer)使用元素测量与索引定位。

- 全文片段搜索、匹配高亮及上一／下一匹配。
- 秒数、`分:秒`、`时:分:秒`跳转，越界时间提示。
- 播放跟随可开关，手动滚动停止跟随。
- 点击片段回听、编辑保留版本、原稿对照、完整导出延续原服务行为。
- 回听清单和修改记录每页 20 条；无分段正文及已完成片段的临时文字按块虚拟展示。

虚拟化减少 DOM 和布局量；任务详情仍按现有接口读取完整正文。本轮没有改成服务端正文分页，也没有宣称网络传输量变小。

## 浏览器验收

在本机独立 mock 工作台使用 **10,800 段、六小时时间轴**、变长段落、200 条复核项及 87 条修改记录测试。音频为稀疏静音 WAV，文字为人工构造的 UI 样本；不作为真实 ASR 准确率或六小时 GPU 质量证据。

| 场景 | 结果 |
| --- | --- |
| 长结果初次打开 | 仅挂载 8 段，页面高度 1000px 与视口一致 |
| 搜索远端片段 | 找到第 10,000 段，唯一匹配并高亮 |
| 编辑和原稿 | 保存为 v2；原稿内容仍可对照；Escape 关闭编辑，打开时聚焦文本框 |
| 全文导出 | 590,793 字符，包含修改及第 10,800 段，未受虚拟列表影响 |
| 时间跳转 | 到 `05:59:50`，远端片段实际可见，播放器同步定位 |
| 播放跟随 | 定位到 4 小时；滚轮操作会关闭跟随 |
| 手机 390×844 | 文档宽高同视口，无整页横向／纵向膨胀；时间跳转可用 |

| 减少动态效果 | 媒体条件生效，页面无 GSAP opacity / transform 入场样式 |
| 管理界面 | 账户列表正常，390px 下无横向溢出 |

`npm run build`（TypeScript + Vite）及 `git diff --check` 通过。构建 JS gzip 131.11 kB、CSS gzip 6.47 kB。界面测试使用 ego-browser；中途一次窄屏操作因浏览器 CDP 模拟在跨调用时被重置而未执行，重新在同一调用内设置视口后完整通过，未将该工具错误当作应用缺陷或通过证据。
