## 限制与过程中修正

- 真实超过 30 分钟、三人混合音轨素材尚未提供，未执行 off／auto 对照，也未评估人物准确率、换号、抢话或长视频同步。人数恰好匹配不能作为质量通过条件。
- 已安装 torch 的元数据未保留下载 URL，缓存检查也未找到可用的官方 wheel 下载记录。本次验证了 CUDA 运行与两种真实模型，保留已有环境；未独立重新证实安装包的下载来源。干净环境复现仍见[未完成事项](../development/roadmap.md)。
- 首次生产 HTTP 验证脚本漏传 MOSS 所需的 `quality_profile=legacy`，提交检查失败；补充参数后通过。其未提交合成上传因秒级时间与脚本微秒范围不一致未被第一轮清理选中，最终按本次生成时间、名称及备份中不存在的 ID 限定清理；最后核对无残留。
- 初次包检查产生了自身的 Python 缓存文件；仅删除这些本次生成的缓存，禁用字节码写入后重新检查通过。首次 GPU 检查的合成 FFmpeg 读取了脚本标准输入，后续改用 `-nostdin`；已通过的模型结果另行读取核实。
- HDR 回看视频暂不支持；旧任务已删除原视频时无法补回。长素材的画质、听感与资源使用仍需真实素材验证。

本地实现、短样例 GPU 功能验证和长面试质量验收分别记录；接口与行为以[工作台契约](../reference/product-workbench.md#视频回看与人物校对schema-6)为准。
